## Spawn 1: Fix Broken UI

**Task:** Investigate and fix critical UI issues identified by Tank's Playwright audit.

**Outcome:** ✅ **SUCCESS** — 5 UI issues fixed

### Issues Fixed

1. **Broken `sm` Breakpoint (Critical)**
   - **File:** `tailwind.config.ts`
   - **Problem:** `extend.screens` had `sm: '375px'`, overriding Tailwind's default 640px. Every `sm:` responsive class (Hero CTA, navbar padding, text) triggered at phone widths instead of tablet.
   - **Fix:** Removed custom `sm`, `md`, `lg` from extend (these match defaults). Now only custom screens like `xs` are overridden.

2. **Selection Styling Invisible**
   - **File:** `globals.css`
   - **Problem:** `::selection` used gradient + `background-clip: text`, which CSS doesn't support for selection. Text highlight was invisible.
   - **Fix:** Replaced with solid `background: #00e5ff` (aurora-cyan).

3. **Sections Hidden Behind Sticky Navbar**
   - **File:** `globals.css`
   - **Problem:** Sticky navbar (80px) had no scroll offset. Anchor links scrolled section headers behind it.
   - **Fix:** Added `scroll-padding-top: 5rem` on `html` and `scroll-margin-top: 5rem` on `section[id]`.

4. **Light Form Controls on Dark Background**
   - **File:** `globals.css`
   - **Problem:** Missing `color-scheme: dark` caused OS-native form controls to render light against dark bg.
   - **Fix:** Added `color-scheme: dark` to `html`.

5. **Featured Tier Card Overflow**
   - **File:** `Tiers.tsx`
   - **Problem:** `scale-105 md:scale-110` at rest caused featured tier to overflow grid cell and overlap adjacent cards.
   - **Fix:** Reduced to `scale-[1.02] md:scale-105` and added `z-10` for proper stacking.

## Spawn 2: Fix Framer Motion Opacity Gating

**Task:** Fix the P0 issue where all sections below Hero are invisible on initial render, SSR, and full-page screenshots.

**Outcome:** ✅ **SUCCESS** — Animations now progressive enhancement only

### Root Cause

Framer Motion's `initial={{ opacity: 0 }}` on `AnimatedSection` and card variants (`cardVariants.hidden`) relied on `whileInView` with IntersectionObserver to reveal content. On static renders (no scroll events), observer never fires — content stays invisible. This breaks:
- SSR (SEO crawlers see empty page)
- Full-page screenshots (Playwright captures blank sections)
- No-JS users and slow connections
- Accessibility (content hidden behind JS-only triggers fails WCAG)

### Changes

Changed all animation initial states to keep opacity visible:

- **AnimatedSection:** `initial: { opacity: 1, y: 20 }` (was `opacity: 0`)
- **DestinationGrid cardVariants:** `hidden: { opacity: 1, y: 20 }` (was `opacity: 0`)
- **ExperienceList cardVariants:** `hidden: { opacity: 1, y: 20 }` (was `opacity: 0`)
- **Tiers cardVariants:** `hidden: { opacity: 1, y: 20 }` (was `opacity: 0`)
- **Testimonials cardVariants:** `hidden: { opacity: 1, y: 20 }` (was `opacity: 0`)
- **StaggerChildren wrapper:** `initial: { opacity: 1 }` (was `opacity: 0`)

Content is always visible on initial render. Scroll animations are subtle slide-ups — progressive enhancement only. `prefers-reduced-motion` is respected automatically by Framer Motion.
