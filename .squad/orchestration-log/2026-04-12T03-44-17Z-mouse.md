## Design System Alignment

Aligns with typography reference: *"Body text should be fixed even on marketing pages"*

**Rationale:**
1. Body copy readability is non-negotiable — 16px minimum across all devices
2. Headings benefit from viewport scaling — display text can adapt
3. Modular scale prevents drift — every size maps to a named token
4. No arbitrary pixels — `text-[1.0625rem]` breaks the system and accumulates over time
5. Performance matters — unused font weights shouldn't load
